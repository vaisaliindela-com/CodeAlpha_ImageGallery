# 🖼️ Image Gallery – CodeAlpha Task 1

## 📌 Project Overview

The **Image Gallery** is a responsive web application developed using HTML, CSS, and JavaScript as part of **Task 1 of the CodeAlpha internship**. It allows users to explore images through an interactive gallery with smooth transitions, image navigation, and a lightbox view.

## 🎯 Objectives

- Design an attractive image gallery using HTML and CSS.
- Implement image navigation using JavaScript.
- Add a lightbox feature to view images in a larger format.
- Create hover effects and smooth transitions.
- Ensure the gallery works on different screen sizes.
- Implement image categories and filtering functionality.

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page.
- **CSS3** – Styling, responsive layout, hover effects, and transitions.
- **JavaScript** – Image navigation, lightbox functionality, and category filtering.

## ✨ Features

- 📸 Interactive image gallery.
- ⬅️ Previous and Next navigation buttons.
- 🔍 Lightbox view for enlarged images.
- 🎨 Hover effects and smooth animations.
- 📱 Responsive design for desktop, tablet, and mobile.
- 🗂️ Image categories such as Nature, Travel, Animals, and Cities.
- 🔎 Filter images by category.

## 📚 Learning Outcomes

Through this project, I improved my understanding of:

- HTML page structure and semantic elements.
- CSS Grid, Flexbox, responsive design, and animations.
- JavaScript event handling and DOM manipulation.
- Creating interactive user interfaces.
- Organizing project files and testing web applications.
